# Дизайн-система — Workshop Planner

## 1. Напрям і антиправила

Інтерфейс проєктується як **робочий журнал локальної майстерні** (за логікою виробничих систем, Linear та технічних креслень): щільність даних, передбачувана навігація, миттєве зчитування термінів, сум і вузьких місць черги.

**Суворо заборонено:**
- фіолетово-сині градієнти, glassmorphism (`backdrop-blur`), неонові тіні;
- емодзі в елементах UI та навігації;
- однакові декоративні картки з іконкою в кружечку;
- надмірні скруглення (`rounded-2xl` і більше);
- hero-банери, вітальні заставки, «lorem ipsum» чи декоративні 3D-ілюстрації.

## 2. Кольорові токени (CSS custom properties)

| Токен | Світла тема | Темна тема (графіт) | Призначення |
|---|---|---|---|
| `--bg-canvas` | `#F7F6F3` | `#171715` | Основне тло сторінки (теплий off-white / графіт) |
| `--bg-surface` | `#FFFFFF` | `#1F1F1C` | Поверхня таблиць, карток, модальних вікон |
| `--bg-subtle` | `#EFECE5` | `#262622` | Бокова панель, шапка таблиць, вторинні блоки |
| `--text-ink` | `#1C1C1A` | `#EEEDE8` | Основний текст, заголовки, значення |
| `--text-secondary` | `#57564F` | `#B0AEA4` | Вторинні описи, підписи |
| `--text-muted` | `#7C7A71` | `#828077` | Назви колонок, підказки, службові метадані |
| `--border-line` | `#E2DFD7` | `#31312C` | Основна межа `1px` замість декоративних тіней |
| `--border-strong` | `#CBC6BA` | `#45443D` | Межі полів вводу, активні обводки |
| `--accent` | `#E8590C` | `#F06418` | Сигнальний помаранчевий — лише для головних дій, активної вкладки та індикаторів терміновості / ризиків |

**Статуси (приглушена палітра низької насиченості):**
- `draft` (Чернетка) — нейтральний теплий сірий;
- `quoted` (Прорахунок) — приглушений сталевий синій;
- `confirmed` (Підтверджено) — приглушений охристий / гірчичний;
- `in_progress` (У роботі) — м’який теракотово-помаранчевий;
- `done` (Виконано) — приглушений оливково-зелений;
- `cancelled` (Скасовано) / `overdue` (Прострочено) — приглушений бордово-червоний.

## 3. Типографіка та форматування даних

- **Текст та заголовки:** `IBM Plex Sans` (fallback: `Inter`, `system-ui`), ваги `400 / 500 / 600`.
- **Числа, ціни, коди замовлень і час:** `IBM Plex Mono` (fallback: `JetBrains Mono`) з обов’язковим `font-variant-numeric: tabular-nums`.
- **Вирівнювання:** текстові колонки — ліворуч; числові, грошові (`Money`), часові тривалості та пріоритети — праворуч.
- **Стандарти форматів:**
  - Гроші: `1 250,00 ₴` (нерозривний пробіл між розрядами, кома для копійок, символ `₴` через пробіл).
  - Дата й час: `21.11 14:30`.
  - Тривалість: `2 год 15 хв` або `45 хв`.

## 4. Сітка, щільність і компоненти

- **Сітка:** базова шкала `8px` (`4px`, `8px`, `12px`, `16px`, `24px`).
- **Скруглення:** `4px` (`rounded`) для кнопок, інпутів, бейджів, комірок; `6px` (`rounded-md`) для контейнерів і модальних вікон.
- **Таблиці (`DataTable`):** висота заголовка `32px`, висота рядка `36–40px`, тонкі межі `1px`, без «зебри» або великих відступів.
- **Порожні стани:** один короткий рядок пояснення суті + одна цільова дія (кнопка), без декоративних іконок чи ілюстрацій.
- **Спільні компоненти (перевикористання в 3+ місцях):**
  - `DataTable`, `StatusBadge`, `Money`, `StatCard`, `PageHeader`, `FormField`, `Modal` / `ConfirmDialog`, `AppShell`.
- **Правила діаграми Ганта (Фаза 6):** чіткі горизонтальні доріжки верстатів на CSS Grid, відрізки переналаштування (`setup`) оформлені діагональним штрихуванням (`.bg-setup-hatch`), запізнілі роботи виділені червоною рамкою, вертикальна сигнально-помаранчева лінія поточного моменту.
