# 2.3. Проєктування веб-інтерфейсу для роботи з даними

> **Статус:** чернетка (Фаза 5 — затвердження дизайн-системи, каркаса та матриці перевикористання компонентів).

## Перевикористання спільних компонентів (вимога: 3+ місця для кожної)

| Компонента | Шлях у проєкті | Де використовується (3+ сторінки / модулі) |
|---|---|---|
| `DataTable` | `client/src/components/DataTable.jsx` | 1. `OrdersPage` (реєстр замовлень)<br>2. `MachinesPage` (парк верстатів)<br>3. `MaterialsPage` (склад і рух залишків)<br>4. `CustomersPage` (клієнти та середній чек) |
| `StatusBadge` | `client/src/components/StatusBadge.jsx` | 1. `OrdersPage` (статуси + rush-мітки)<br>2. `OrderDetails` / модальний інспектор<br>3. `MaterialsPage` (мітка низького залишку)<br>4. `Planner` (запізнення та статус блоку) |
| `Money` | `client/src/components/Money.jsx` | 1. `OrdersPage` (собівартість, ціна, KPI сума)<br>2. `OrderWizard` (live-калькуляція позицій)<br>3. `OrderDetails` (детальна розбивка)<br>4. `CustomersPage` та `Analytics` |
| `StatCard` | `client/src/components/StatCard.jsx` | 1. `OrdersPage` (4 оперативні метрики)<br>2. `Dashboard` (ключові KPI цеху)<br>3. `Planner` (запізнення, setup, makespan)<br>4. `Analytics` (виручка, прибуток, маржа) |
| `PageHeader` | `client/src/components/PageHeader.jsx` | Усі 8+ робочих сторінок (`Orders`, `Dashboard`, `Planner`, `Machines`, `Materials`, `Customers`, `Analytics`, `Settings`) |
| `FormField` | `client/src/components/FormField.jsx` | 1. `LoginPage`<br>2. `OrdersPage` (інспектор замовлення)<br>3. `OrderWizard`<br>4. `Machines`, `Materials`, `Settings` |
| `Modal` / `ConfirmDialog` | `client/src/components/Modal.jsx` | 1. `OrdersPage` (інспектор + підтвердження зміни статусу/видалення)<br>2. `Planner` (редагування/закріплення слоту)<br>3. `Machines` (вікно ТО) та `Materials` (коригування залишку) |
