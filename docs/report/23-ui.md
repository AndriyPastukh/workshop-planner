# 2.3. Проєктування веб-інтерфейсу для роботи з даними

> **Статус:** синхронізовано з повною реалізацією інтерфейсу (11 маршрутів / 10 робочих сторінок без заглушок).

## Карта сторінок застосунку

| Маршрут | Сторінка | Призначення та ключові дії |
|---|---|---|
| `/login` | `LoginPage` | Автентифікація за `email` та паролем, перемикання теми |
| `/` | `DashboardPage` | Оперативні KPI, запізнення, завантаження верстатів, найближчі дедлайни, ризики складу |
| `/orders` | `OrdersPage` | Реєстр замовлень, фільтрація, пошук, створення замовлення з live-чеком |
| `/orders/:id` | `OrderDetailsPage` | Картка замовлення, чек собівартості, матеріали, історія статусів, друк КП і Наряду |
| `/planner` | `PlannerPage` | Діаграма Ганта на CSS Grid, лінія «Зараз», `ATCS/EDD/SPT/FIFO`, Batch Split, CSV/PDF, «Чи встигну?» |
| `/what-if` | `WhatIfPage` | Симулятор «Що якщо?» (+віртуальні верстати, $k_1/k_2$, тарифи) з порівнянням `Δ` |
| `/machines` | `MachinesPage` | Довідник верстатів, погодинна ставка, графік змін та вікна ТО |
| `/materials` | `MaterialsPage` | Склад матеріалів (`stockQty`, `reservedQty`, `availableQty`), прогноз дефіциту, прихід і журнал рухів |
| `/customers` | `CustomersPage` | База клієнтів, загальна виручка, середній чек, історія замовлень |
| `/analytics` | `AnalyticsPage` | Виручка, собівартість, прибутковість за типами обладнання, ТОП-клієнти |
| `/settings` | `SettingsPage` | Тарифи/знижки/$k_1, k_2$, напрямлена матриця `setup_rules`, шаблони виробів (`owner`-редагування) |

## Список звітних та друкованих форм

1. **Комерційна пропозиція (КП № …)** — друкована A4-форма (`OrderDetailsPage`, кнопка «КП (PDF)» через `@media print`) із переліком позицій і підсумком для клієнта без розкриття внутрішньої маржі.
2. **Виробниче наряд-завдання (Наряд № …)** — цехова A4-форма (`OrderDetailsPage`, кнопка «Наряд (PDF)») із призначеними верстатами/слотами, планом витрати матеріалів, нормою часу й контрольним листом оператора.
3. **Графік та план виробництва (CSV / PDF)** — експорт черги у форматі UTF-8 BOM CSV (`buildScheduleCsv`) та друкована версія діаграми Ганта (`PlannerPage`).
